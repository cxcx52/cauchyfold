# Earlier compact parameters

These profiles precede the shared-center CBC bound and the updated norm and rank parameters. Their saved values remain unchanged for comparison with the [current profiles](../../profiles/compact/).

- [Finite arities](finite-arities/): parameter-grid results and encoding checks.
- [Arity 1024](arity-1024/): sparse compiler artifacts, field transcript, and the earlier estimator results.

The current model retains the block/radix schedules and front-end encoding from these profiles. Communication, kernel radii, and attack estimates must be read with the parameter set that produced them.
